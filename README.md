# Khanak Jain — Digital Fieldnotes

A responsive, terminal-inspired personal portfolio for Khanak Jain.

## Run locally

Open `index.html` in a browser. The site uses plain HTML, CSS, and JavaScript and has no build step or package dependencies. The typefaces load from Google Fonts when a network connection is available; system fallbacks are provided.

## Update the archive

Edit the `portfolio` object near the top of `script.js` to update project descriptions, contributions, verified repository/demo URLs, and personal contact links. Empty URLs are intentionally hidden or shown as unavailable.

## Files

- `index.html` — semantic page structure and metadata
- `styles.css` — responsive visual system and motion
- `script.js` — project data, navigation, command palette, and interactions
